## 2026-11-08 蓄力环：玩家触发花式
- 屏幕旁边常驻一个圆形蓄力环，不管 debug 开没开都显示，状态好坏都显示。
- 女孩不再主动做花式（飞板、跳舞等）。平时只做上下板、转身、回头这类日常动作。
- 触发条件：速度到一定程度，并且蓄力满。
- 满足以后就一直保持"蓄着"的状态，女孩回头看镜头（看玩家），像在等我们。
- 玩家按回车、按空格、鼠标点击或点圆环 → 释放花式。
- 条件不满足时，圆环显示进度：蓄力百分比加速度是否够。

## 2026-11-08 体力 / 上下板决策（Cheney 口述，待实现）
决策时同时看三样东西：1. 劳累程度（体力） 2. 当前速度 3. 前方一段路的地形（会不会马上又来一段上坡或下坡）。
- 消耗：
  - 走路一直消耗。
  - 上坡时走路比推板省力；推板消耗最多。
- 恢复：
  - 在板上滑行时慢慢恢复。
  - 停下来休息恢复得更快。
- 体力耗到 0：在路边停下，坐在板上休息，恢复后再出发。
- 花样：体力超过 70%，并且速度到了一定程度，才可以做（由玩家触发）。
  - 做花样消耗体力，也消耗速度。
  - 所以花样同时是长下坡的减速手段。
- 现象：她在一段很长的 10° 以上下坡上一直走路，不合理。上下板逻辑整体有点乱，要按上面三个因素重做。
- 速度太快时不能做花样（危险），只能刹车。
- 一直往下滑、速度持续上升时，切换成冲刺姿态（低身、压低重心）。
- 测试场地要把这些情况都做出来：长缓下坡、长陡下坡、长上坡、体力耗尽的长坡、平路休息区，逐个测试。
- Debug 菜单旁边加一个场地菜单，可以切换"练习场"和"实际场（Bondi 等真实路线）"。
- 练习场：没有真实景物（建筑、景点），但各种地形都有（见上面的测试列表），专门用来调上下板、体力和花样的逻辑。
- 场地实际分两种，"实际场"又分两种，共三档：
  1. 练习场：人工设计的各种地形，没有景物。
  2. 真实数据·未渲染：直接用地图下载的真实路径和高程（坡度、弯道都是真的），只用最简单的方块和地面，不做美术，用来快速测逻辑。
  3. 真实场·已渲染：Bondi 这种做完路面、草地、树的完整场景。

## 2026-11-08 产品定位（Cheney）
- 数值和规则尽量贴近真实生活，包括体力、速度、坡度、能不能滑。
- 两个用途：
  1. 休闲观景：跟着女孩看真实城市的风景。
  2. 给长板爱好者做实用参考：帮他们挑选各个城市、各个地方适合户外长板的路线，看哪段能滑、哪段要下板走、坡度多大、累不累。
- 所以模拟出来的路线结论（哪里下板、哪里能放坡、哪里要休息）要真实可信，将来可以当作路线评价数据展示出来。

## 2026-11-08 跟拍镜头 = 无人机（Cheney）
- 跟拍镜头模仿无人机：一直盯着她，运动平稳。
- 要避障：镜头和她之间、或镜头前进方向上要撞到东西（树、建筑、山坡）时，就把镜头抬高。
  - 抬到刚好能越过障碍的高度就停，不要一直往上抬。
  - 越过障碍后再慢慢降回原来的高度。
- 自由看景：用户拖动画面，镜头就可以转去看想看的风景。
  - 镜头仍然跟着她往前移动，但女孩可以暂时不在画面里。
  - 用户松手、一段时间不操作后（比如 4–6 秒），镜头再平滑地转回来，重新对准女孩。
  - 自由看景期间，"她必须一直在屏幕里"那条规则暂时不生效。
